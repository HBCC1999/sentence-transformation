### Download
Head to [the releases page](https://github.com/HBCC1999/sentence-transformation/releases/tag/v1.0), scroll down and download the .exe file. Then place it anywhere on your computer and double-click to run. Make sure you are on Windows (10 or newer).

### Contribution
Think you can make the program even better? Fork this repository and continue building on the program! Lets make it even better!

### Safety Concerns
The program is completely safe to run and use! If windows tells you that the program might be dangerous, then that's a common windows problem with small-scale apps and executables.
